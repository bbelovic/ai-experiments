# Mission: Build and explain an AI financial research assistant

## Why
Build practical skills relevant to the enterprise AI engineering job posting discussed in this workspace. Evolve the existing financial-data project into a Java/Spring AI assistant, and be able to explain, implement, evaluate, and secure its use of tools, MCP, and retrieved evidence.

## Success looks like
- Explain model context, tool calling, MCP, retrieval, RAG, and grounding using this application's request flow.
- Expose existing financial-data services through MCP and consume them from an assistant.
- Answer filing questions with retrieved evidence, traceable citations, and explicit handling of missing information.
- Enforce authenticated access to synthetic private notes and demonstrate denial across team boundaries.
- Evaluate representative questions, diagnose failures, and demonstrate a deployed prototype with documented limits.

## Constraints
- The learner already knows Spring Framework and Spring Boot; Spring AI is new.
- Stay with Java and Spring AI. No Python prerequisite.
- Reuse the repository; pair short conceptual lessons with incremental implementation exercises.
- Time and API budget are not yet specified. Start with local fixtures and avoid paid calls in introductory lessons.

## Out of scope
- Python study as a prerequisite, model training, and a broad survey of every AI platform.
- Relearning Spring Boot fundamentals.
