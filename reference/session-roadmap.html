JAVA + SPRING AI / LEARNING PLAN

From financial data to a dependable assistant

Mission · Sources · Teaching notes

The teach skill is the learning scaffold. Small implementation tasks in this repository provide the practice. Knowing Spring Boot lets us focus on AI-specific decisions.

Five lessons are ready. Lesson 4's model calls and response inspection have been demonstrated with Gemini. Lesson 5 returns to local tests: first a Java tool contract, then a Spring AI callback. Later sessions are planned, not pre-written.

How a session works

  1. Recall two earlier ideas without reading.
  2. Learn one new concept with a repository example.
  3. Predict behavior, then try a small task.
  4. Explain the result and receive feedback.

Revisit a concept at the next session and again after two or three later sessions. Progress is based on your explanations and working changes, not pages opened. Ask Codex to explain anything unclear.

Scope and job relevance

Sessions 4-7 address model integration and tools; 8-10 address RAG and grounding; 11 addresses identity and permissions; 12-14 address automation, evaluation, and deployment. This plan does not establish Copilot Studio, SharePoint, or enterprise platform administration experience. Add a focused platform exercise later if the target role requires it.

Primary sources for the sequence: Spring AI tool calling, MCP architecture, and Spring AI RAG. Start with lesson 1; its recommended reading is the tool-calling architecture overview.
