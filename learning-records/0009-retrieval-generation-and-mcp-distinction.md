# Retrieval, generation, and MCP distinction

In the final recall exercise for lesson 0003, the learner correctly explained that retrieval supplies evidence as context for generation, that the model can still interpret evidence incorrectly and produce an inaccurate answer, and that MCP is a protocol while RAG is an application pattern. This demonstrates the conceptual distinctions targeted by the lesson.

Use the explicit diagnostic label generation/grounding failure when the correct evidence reaches the model but its answer invents a claim. Future sessions can move into a small Spring AI implementation while revisiting these distinctions through request inspection and evidence checks.
